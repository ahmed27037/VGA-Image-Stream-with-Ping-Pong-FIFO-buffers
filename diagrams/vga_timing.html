Operation Phases
Phase 1: Initialization (FIFO Priming)
• System starts with priming = 1
• Write control accumulates exactly 640 pixels into Buffer 0
• VGA timing generator held in reset (vga_rst_n = 0)
• Prime counter counts down 640 cycles
• Once buffer ready AND prime counter = 0: Release VGA (vga_rst_n = 1)
• Switch to DE-locked write mode (priming = 0)
Phase 2: Normal Operation (Ping-Pong)
• Write Side: Locks to DE signal from VGA timing generator
  - Write active when DE = 1
  - Write line start on DE rising edge
  - Write line end on DE falling edge
• Read Side: Consumes pixels synchronized to VGA display
  - Read active when DE = 1 (consume signal)
  - First pixel: Line-start bypass (combinational)
  - Subsequent pixels: Indexed by x coordinate
• Buffer Switching: Seamless ping-pong between buffers
Phase 3: Reverse Mode (Optional)
• When reverse = 1, each line is read in reverse order
• Address calculation:
  - Forward: mem[r_sel][x] where x = 0 to 639
  - Reverse: mem[r_sel][639 - x] where x = 0 to 639
• Creates horizontal flip effect on display
• Reverse flag latched per line (r_reverse)
Data Flow Example
Cycle-by-Cycle Example (Line 0)
Cycle 0 (Line Start):
• DE rises → write_line_start = 1, read_line_start = 1
• Write: Select Buffer 0, write pixel[0] to mem0[0]
• Read: Select Buffer 0 (ready), output mem0[0] via bypass (start_data)

Cycles 1-638:
• Write: mem0[x] = in_data (x = 1 to 638)
• Read: step_data = mem0[x] (x = 1 to 638)

Cycle 639 (Line End):
• Write: mem0[639] = in_data, mark ready0 = 1
• Read: step_data = mem0[639], DE falls → read_line_end = 1

Next Line (Line 1):
• Write: Switch to Buffer 1, begin writing
• Read: Continue with Buffer 0 until line complete, then switch
