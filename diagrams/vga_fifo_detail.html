Ping-Pong FIFO Buffer - Detailed Architecture
FIFO Buffer Architecture
Write Side (Continuous Source)
Write Control
• Line counter: p_x (0 to H_ACTIVE-1)
• Buffer selection: w_sel (0 or 1)
• Writing state: Active when writing a line
• Line start detection: write_line_start
• Line end detection: write_line_end
Write Operation
• Chooses free buffer (prefer opposite of read buffer)
• Writes pixels when in_valid && write_active
• Marks buffer ready when line complete
• Handles overflow: Error if both buffers busy
Read Side (VGA Display)
Read Control
• Column address: read_col = x (from VGA)
• Buffer selection: r_sel (0 or 1)
• Reading state: Active when consuming a line
• Reverse flag: Latched per line
• Line start detection: read_line_start
• Line end detection: read_line_end
Read Operation
• Chooses ready buffer (prefer buffer 0)
• Line-start bypass: First pixel immediate (combinational)
• Step output: Indexed by read_col
• Reverse mode: Address = H_ACTIVE - 1 - read_col
• Handles underflow: Error if no ready buffer
Line Buffer Structure
Buffer 0
mem0[0] - Pixel 0
mem0[1] - Pixel 1
mem0[2] - Pixel 2
...
mem0[639] - Pixel 639
ready0: Status flag
Buffer 1
mem1[0] - Pixel 0
mem1[1] - Pixel 1
mem1[2] - Pixel 2
...
mem1[639] - Pixel 639
ready1: Status flag
Output Generation Logic
Line-Start Bypass (Combinational)
start_valid = read_line_start && consume && (ready0 || ready1)
start_data = (use_buf0) ? mem0[reverse?639:0] : mem1[reverse?639:0]
Available same cycle as read_line_start assertion
Step Output (Indexed Read)
step_valid = reading && consume
col_fwd = read_col
col_rev = H_ACTIVE - 1 - read_col
step_data = (r_sel==0) ? mem0[reverse?col_rev:col_fwd] : mem1[reverse?col_rev:col_fwd]
Registered Output
out_valid: Registered version of step_valid
out_data: Registered version of step_data
Updated every consume cycle when reading
Operation Flow
1. Write Side: Continuously fills one buffer at a time. When write_line_start, selects free buffer and begins writing pixels.
2. Line Complete: When 640 pixels written (or write_line_end), marks buffer as ready (ready0 or ready1 = 1).
3. Read Side: When read_line_start, selects ready buffer (prefers buffer 0 if both ready). Outputs first pixel immediately via bypass.
4. Normal Read: Subsequent pixels read using read_col index. Forward: mem[r_sel][read_col], Reverse: mem[r_sel][H_ACTIVE-1-read_col].
5. Line End: When read_line_end, marks buffer as not ready, releases buffer for writing.
6. Ping-Pong: While reading from one buffer, writing continues to the other buffer. Seamless switching between buffers.
