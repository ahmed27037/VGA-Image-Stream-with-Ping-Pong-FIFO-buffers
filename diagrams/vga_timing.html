Operation Phases
Phase 1: Initialization (FIFO Priming)
• System starts with priming=1
• Accumulates 640 pixels into Buffer 0
• VGA held in reset (vga_rst_n=0)
• Prime counter counts 640 cycles
• Buffer ready AND counter=0: Release VGA (vga_rst_n=1)
• Switch to DE-locked mode (priming=0)
Phase 2: Normal Operation (Ping-Pong)
• Write: Locks to DE signal
  - Active when DE=1
  - Line start on DE rising edge
  - Line end on DE falling edge
• Read: Consumes pixels sync'd to VGA
  - Active when DE=1
  - First pixel: Line-start bypass
  - Subsequent: Indexed by x
• Buffer Switching: Seamless ping-pong
Phase 3: Reverse Mode (Optional)
• When reverse=1, each line read in reverse
• Forward: mem[r_sel][x] where x=0-639
• Reverse: mem[r_sel][639-x] where x=0-639
• Creates horizontal flip
• Reverse flag latched per line
Data Flow Example
Cycle-by-Cycle Example (Line 0)
Cycle 0 (Line Start):
• DE rises → write_line_start=1, read_line_start=1
• Write: Select Buffer 0, write pixel[0] to mem0[0]
• Read: Select Buffer 0 (ready), output mem0[0] via bypass

Cycles 1-638:
• Write: mem0[x] = in_data (x=1-638)
• Read: step_data = mem0[x] (x=1-638)

Cycle 639 (Line End):
• Write: mem0[639] = in_data, mark ready0=1
• Read: step_data = mem0[639], DE falls → read_line_end=1

Next Line (Line 1):
• Write: Switch to Buffer 1, begin writing
• Read: Continue Buffer 0 until complete, then switch
