Ping-Pong FIFO Buffer - Detailed Architecture
FIFO Buffer Architecture
Write Side (Continuous Source)
Write Control
• Line counter: p_x (0 to 639)
• Buffer select: w_sel (0/1)
• Writing state: Active
• Line start/end detection
Write Operation
• Chooses free buffer
• Writes when in_valid && active
• Marks ready when line complete
• Handles overflow error
Read Side (VGA Display)
Read Control
• Column: read_col = x
• Buffer select: r_sel (0/1)
• Reading state: Active
• Reverse flag latched
• Line start/end detection
Read Operation
• Chooses ready buffer
• Line-start bypass: Immediate
• Step output: Indexed
• Reverse: H_ACTIVE-1-x
• Handles underflow error
Line Buffer Structure
Buffer 0
mem0[0] - Pixel 0
mem0[1] - Pixel 1
...
mem0[639] - Pixel 639
ready0: Status
Buffer 1
mem1[0] - Pixel 0
mem1[1] - Pixel 1
...
mem1[639] - Pixel 639
ready1: Status
Output Generation Logic
Line-Start Bypass (Combinational)
start_valid = read_line_start && consume && (ready0||ready1)
start_data = (use_buf0) ? mem0[reverse?639:0] : mem1[reverse?639:0]
Step Output (Indexed Read)
step_valid = reading && consume
col_fwd = read_col | col_rev = H_ACTIVE-1-read_col
step_data = (r_sel==0) ? mem0[reverse?col_rev:col_fwd] : mem1[reverse?col_rev:col_fwd]
Registered Output
out_valid: Registered step_valid | out_data: Registered step_data
Operation Flow
1.Write: Fills one buffer. On write_line_start, selects free buffer, writes pixels.
2.Line Complete: After 640 pixels, marks buffer ready (ready0/ready1=1).
3.Read: On read_line_start, selects ready buffer, outputs first pixel via bypass.
4.Normal Read: Subsequent pixels via read_col index. Forward: mem[r_sel][read_col], Reverse: mem[r_sel][639-read_col].
5.Line End: On read_line_end, marks buffer not ready, releases for writing.
6.Ping-Pong: While reading one buffer, writing continues to the other.
